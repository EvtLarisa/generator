# generator

Модель тактового генератора широтно-импульсной модуляции (ШИМ) и программа экспериментов с
мутационными проверяющими тестами для его хвостовой компоненты к статье «Исследование мутационных
проверяющих тестов для компонентов автоматных сетей» (журнал «Информационные технологии»), п. 3.3,
рис. 12-14.

Связанные репозитории:

- генератор случайных автоматов - https://github.com/EvtLarisa/fsm-generation;
- эксперименты с мутационными тестами на случайных автоматах -
  https://github.com/EvtLarisa/mutation-based-checking-tests.

Интерактивная модель генератора и построенных тестов:
https://justkeonix.github.io/public-pages/pwm-test-through-counter.html

## Модель

Генератор ШИМ состоит из счетчика, компаратора и RS-триггера и представляется бинарной
последовательной композицией A∙B:

- A - счетчик по модулю M с разрешением счета: вход en (`s` - хранение, `c` - счет), выход - новое
  значение счетчика (внутренний канал U = {0, ..., M-1});
- B - компаратор с RS-триггером: при значении счетчика 0 триггер устанавливается, при значении h
  сбрасывается, иначе хранит состояние; выход pwm - новое состояние триггера, т. е. pwm = 1, пока
  счетчик идет от 0 до h-1.

Входы подаются только на счетчик, значение счетчика не наблюдается, наблюдается только выход pwm.
Проверяется хвостовая компонента B; головная компонента (счетчик) считается исправной.

Таблицы переходов A, B и автомата-композиции печатает `pwm_model.py`; для M = 8, h = 3 они сохранены
в `models/pwm_M8_h3.txt` (в композиции из начального состояния достижимы 11 из 16 пар состояний).

## Установка

Нужен Python 3.8 или новее, библиотека `networkx` (проверено на версии 3.7) и `matplotlib` (только для
рисунков).

```bash
git clone https://github.com/EvtLarisa/generator.git
cd generator
pip install -r requirements.txt
```

Все команды ниже запускаются из корня репозитория.
